Overview

This Calgary Stampede festival guide redesign and event poster is a student final project created for a graphic design class. Working together with Paola, we transformed the original guide by creating our own graphics, designing page layouts and determining the overall aesthetic we wanted to showcase for the event with selecting typography and composing colour palettes. We focused on achieving a rodeo, western look to showcase the exciting event for all ages.

Additional Notes: Vector graphics used in this project are designed by the team. The image used of the Scotiabank Saddledome belongs to its respective owners. This project is not affiliated with the Calgary Stampede.
