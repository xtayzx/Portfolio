Project Overview

Shroomie is a desktop web camera conceptual design created for a student final project for a materials in design class. In creating the camera, the restrictions placed on us for the cameras design was that it had to be designed with wood and fabric. Our design was conceptualized with the ideal user being a college student, who would want a web camera that is compact, portable as well as usable as a home decor element in a office environment.
